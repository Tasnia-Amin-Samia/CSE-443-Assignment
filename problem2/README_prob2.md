# Bank Marketing Prediction using Logistic Regression

## Overview

This project uses **Logistic Regression** to predict whether a bank customer will subscribe to a term deposit.

The project is implemented in Python using Google Colab and uses the Bank Marketing dataset loaded from Google Drive.

## Dataset

The dataset contains **45,211 records** and **17 columns**.

The target column is:

```text
y
```

where:

- `no` → 0
- `yes` → 1

### Target Distribution

| Target | Count |
|---|---:|
| No | 39,922 |
| Yes | 5,289 |

The notebook reports no missing values in the dataset.

## Features

### Numerical Features

- age
- balance
- day
- duration
- campaign
- pdays
- previous

### Categorical Features

- job
- marital
- education
- default
- housing
- loan
- contact
- month
- poutcome

## Data Preprocessing

The notebook uses a `ColumnTransformer` to apply different preprocessing techniques to numerical and categorical features.

### Numerical Features

`StandardScaler` is used to standardize numerical features.

### Categorical Features

`OneHotEncoder` is used to convert categorical features into numerical representations.

The encoder uses:

```python
handle_unknown="ignore"
```

The preprocessing and classifier are combined into a single Scikit-learn `Pipeline`.

## Train-Test Split

The dataset is divided into training and testing sets using:

```text
Test size: 20%
Random state: 42
Stratification: Yes
```

Resulting shapes:

| Split | Shape |
|---|---:|
| Training | 36,168 × 16 |
| Testing | 9,043 × 16 |

## Model

The classification model is:

**Logistic Regression**

Configuration:

```python
LogisticRegression(
    max_iter=1000,
    random_state=42
)
```

The complete pipeline is:

```text
Raw Data
   ↓
ColumnTransformer
   ├── Numerical → StandardScaler
   └── Categorical → OneHotEncoder
   ↓
Logistic Regression
   ↓
Prediction
```

Classification results:
